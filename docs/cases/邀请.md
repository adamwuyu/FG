1. 网站打开任意网址，自动访问接口
http://localhost:3000/api/proApi/support/user/team/list?status=waiting

2. 经过node server，通过/pages/api/proApi/[...path].ts自动路由后实际访问'http://localhost:3002/api/support/user/team/list?status=waiting'

3. 如果用户在team_members表中的status为waiting的，弹出“处理邀请”模态框。询问接受还是拒绝

4. 点击“接受”后，调用http://localhost:3000/api/proApi/support/user/team/member/updateInvite接口
方法：put
参数：{status: "active", tmbId: "*******"}

5. 点击“拒绝”后，调用http://localhost:3000/api/proApi/support/user/team/member/updateInvite接口
方法：put
参数：{status: "reject", tmbId: "*******"}
