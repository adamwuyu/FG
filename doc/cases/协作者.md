### 协作者接口规范

#### 1. 获取协作者列表接口

```
GET /api/proApi/core/app/collaborator/list
```

**请求参数**:
- `appId`: string (查询参数) - 应用ID

**响应数据**:
```typescript
CollaboratorItemType[] = {
  teamId: string;       // 团队ID
  permission: Permission; // 权限级别
  name: string;         // 协作者名称
  avatar: string;       // 头像URL
  // 以下三个字段只会有一个存在
  tmbId?: string;       // 成员ID
  groupId?: string;     // 群组ID
  orgId?: string;       // 组织ID
}
```

#### 2. 添加/更新协作者接口

```
POST /api/proApi/core/app/collaborator/update
```

**请求体**:
```typescript
{
  appId: string;        // 应用ID
  permission: PermissionValueType; // 权限值类型
  // 以下三个字段可以同时存在，但至少需要一个
  members?: string[];   // 成员ID列表
  groups?: string[];    // 群组ID列表
  orgs?: string[];      // 组织ID列表
}
```

#### 3. 删除协作者接口

```
DELETE /api/proApi/core/app/collaborator/delete
```

**请求参数**:
```typescript
{
  appId: string;        // 应用ID
  // 以下三个字段只能有一个存在
  tmbId?: string;       // 成员ID
  groupId?: string;     // 群组ID
  orgId?: string;       // 组织ID
}
